# Application de Gestion des Stagiaires - Macrotech

## Description
Phase 1 (Frontend) du projet de gestion interne des stagiaires. Cette application permet de suivre les stagiaires, leurs projets, et leur avancement.

## Technologies
- HTML5 Sémantique
- CSS3 (Variables, Animations)
- Bootstrap 5
- JavaScript Vanilla (ES6+)

## Installation
1. Cloner ce dépôt
2. Ouvrir `index.html` dans un navigateur ou utiliser Live Server.
